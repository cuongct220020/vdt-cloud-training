# Poker

## Introduction

Poker hands are ranked according to a well-known hierarchy of hand types, from a simple high card up to a royal flush, and comparing hands against that hierarchy is a classic exercise in reasoning about rules and tie-breaking logic.

## Instructions

See [Wikipedia](https://en.wikipedia.org/wiki/List_of_poker_hands) for an overview of poker hands.
